## Complete independent codec capability

New core/model `DeckPayloadCodecPort`:

```kotlin
interface DeckPayloadCodecPort {
    fun encodeSnapshot(value: DeckSnapshot): Outcome<SnapshotBytes>
    fun decodeSnapshot(payload: SnapshotBytes): Outcome<DeckSnapshot>
}
```

New model `DeckPayloadLimits` constants: encoded bytes8MiB; entries10000; categories1024; individual list elements10000; cumulative declared collection elements100000; individual text UTF8 bytes1MiB; IDs UTF8 bytes1024; exact decimal precision4096digits. Bounds fail explicitly, never truncate. ID checks bound length/UTF8 without changing source qualification. Strings use strict Unicode/UTF8, not replacement. Validate length/count before allocation; cumulative list budget is charged before list allocation. Output limit is a wire-byte bound, not an identical backing-buffer/RAM claim. Keep actual memory/performance evidence separate.

Implementation data/storage/decks/codec is separate from life CLIF. New wire magic CLDK, big-endian unsigned16 version1. Encode complete DeckSnapshot field order (existing declared order followed by primer/categoryOrder), every nested entry/identity/Knowledge reason+evidence/labels/role override/budget/native unit/snapshot reference/package-instance contribution. Stable enum names framed as bounded UInt32-length UTF8, not ordinals; source-qualified IDs use provider then raw, each bounded UTF8 frame, EntityId uses its one value. Nullable/presence tags0 absent/1 present, DecimalUnit tags0Fiat (currency string)/1Tix (no body)/2Native (provider then symbol). Knowledge tags (Known0/Absent1/Unknown2); list count unsigned32 read into Long and constrained before narrowing/allocation; cumulative budget arithmetic checks remaining budget before addition to prevent overflow; text byte length unsigned32 then strict UTF8, length must fit field cap AND remaining payload before allocation. SnapshotBytes.size is checked before copyBytes. IDs use their1024byte cap before encoding allocation. Quantity/contribution counts are signed32 constrained by actual DTO constructors. IDs retain both provider and raw values. UTC is signed64 seconds+signed32 nanos with actual constructor validation. Revision signed64 nonnegative. Boolean single byte0/1. BigDecimal is exact signed unscaled decimal text plus signed32 nonnegative scale; check stored DecimalAmount.precision before expanding/stringifying unscaled value; decode integer frame bounded to4096digits plus optional minus before BigInteger construction; canonical unscaled grammar is `0` or `-?[1-9][0-9]*` (no +, leading zeros or -0); never toPlainString with huge scale. DecimalAmount scale/precision reconstructed exactly using current constructor, no float/rounding/FX. No custom normalization or source authority.

Encode structural/budget failure => Failure INVALID_INPUT; decode malformed/truncated/unknown tag/invalid enum/constructor/oversize/trailing bytes => Failure CORRUPT_DATA; wire version0 => CORRUPT_DATA; known magic/newer wire version => Unavailable UNSUPPORTED before body parsing. No file/network/key acquisition or optional-download effect. Codec preserves structurally typed content; decoding grants no category/package/source/repository authority. Semantic edit/repository graph validation stays in decks; do not duplicate a business validator in storage or add a production reverse edge. No life format/schema change or new dependency pin.
