LifeRandomEngine.resolve(snapshot, GameAction, at:UtcTimestamp, random:RandomSource, context:RandomRequestContext?) -> Outcome<RandomReduction(snapshot,action,recorded)>. Accept single RequestRandom only; reject completed game and groups before any draw. Validate whole snapshot first. Does not settle timing/revision/event pointer; outer engine supplies same settled snapshot/time and performs single final commit. RandomSource is explicit, no hidden randomSeed implementation. Failed resolution can consume ephemeral draws but returns no partial state; only committed actual values become durable truth.

Context is bounded trusted service input containing original RandomRequest and last committed RecordedRandomResult for this request, never whole history. Service authenticates same-game request/batch uniqueness and the complete latest committed batch chain including events later undone; this data class is not a capability or proof. A new request needs absent context; existing context with repeated initial request is invalid/no draws (committed transaction retries are handled by service, not redrawing). ContinueDice requires context original Dice, matching request IDs, valid previous dice value/sides/requested, remaining>0 and exactly last.batchIndex+1 with overflow guard. Do not accept skipped/replayed batches or invent original request from current continuation. Guard arithmetic before multiplying; derive owed from checked prior remainder. Request/batch IDs persist even after undo; undo never erases randomness audit or makes a committed batch drawable again.

Coin maps accepted CoinFace to heads. SeatPick eligible is current Active seats in table order; validate supplied asker exists if nonnull, opponentsOnly excludes asker; zero eligible records selected=null and consumes no draws; singleton no draw. Never pick eliminated seats. SeatOrder permutes ALL roster seats once via RandomTools.randomizeSeats, retaining participation/identities and explicit RequestRandom in log; record exact chosen order, no double-randomization or hidden canonical Reorder action substitution.
