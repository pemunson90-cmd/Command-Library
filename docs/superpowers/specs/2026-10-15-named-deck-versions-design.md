## Outcome and complete capability

Enumerate immutable named checkpoints, preview a complete historical diff, restore without content loss, and keep an enumerable pre-restore recovery checkpoint. Existing deck_revision history is not this feature. Reuse DeckVersion and DeckDocumentDiff, not the unimplemented aggregate DeckRepository.

Proposed LocalDeckVersions methods (all suspend, final CancelToken, Outcome):

- capture(id:DeckId, expected:Revision, label:String, operationId:EntityId):DeckVersion
- list(id:DeckId, page:PageRequest):Page<DeckVersionSummary>
- load(id:DeckId, versionId:EntityId):DeckVersion
- previewRestore(id:DeckId, versionId:EntityId, expected:Revision):DeckRestorePreview
- restore(id:DeckId, versionId:EntityId, expected:Revision, recoveryLabel:String, operationId:EntityId):DeckRestoreResult

DeckVersionSummary contains existing DeckVersion metadata except manifest, plus kind USER/RECOVERY and nullable restoredTargetVersionId. DeckRestorePreview contains actual current DeckSnapshot, selected DeckVersion and complete DeckDifference. It predicts neither future time nor write authority. DeckRestoreResult contains committed DeckSnapshot and exact recovery DeckVersion. Restore independently rereads all inputs transactionally. Existing DTO/wire types are not silently changed.

Labels exact/nonblank strict UTF-8 <=1024bytes; duplicate labels allowed. Local provider/deck IDs and operation/version IDs use existing identifier bounds. Wrong deck/version pair is NOT_FOUND, malformed input INVALID_INPUT; mismatched expected STALE_REVISION; contradictory retained storage CORRUPT_DATA; known unsupported wire remains UNSUPPORTED. CancellationException propagates; unknown acknowledgement may have committed. No zero/missing substitution, no implicit downloads or catalog authority.

## Durable ordering, integrity and replay

One additive deck_named_version table references immutable deck_revision bytes, not duplicate payloads: globally unique version ID, provider/deck, exact label/capture time/source revision, unique creating deck_operation sequence, predecessor version ID, kind, optional selected restore target. Composite same-deck foreign keys for source/pred/target, creating sequence FK to receipt. Predecessor is the immediately preceding named checkpoint by creation sequence, including recovery; never selected target or logical undo pointer. Verify indexed actual prior sequence, not just valid FK. Add indexes for deck/creation-sequence and same-deck referenced keys. Root owns next migration ordering/Room exports; do not assume schema number until accepted.

Private canonical framed metadata SHA binds deck/version IDs, exact label/time/source revision, predecessor/kind/target and creating sequence. This detects accidental metadata or valid-FK swaps, not malicious database rewriting. Load/replay validates metadata, creating receipt kind/deck/revision and historical payload hash/graph. List validates bounded metadata/receipt relationships and immediate predecessor, without claiming unread payload integrity. No unbounded scan of all checkpoints.

Capture checks replay first, then current head/CAS and admissibility; creates only receipt+checkpoint, no content revision, undo group or head write. Distinct operations can checkpoint identical content. One injected clock and generated checkpoint ID only after admissibility; now >= current modified/created and prior capture time. Equal time allowed. Collision/exhaustion fail atomically. Clock/ID exceptions map INTERNAL except cancellation.

Restore checks replay before mutable state/clock/IDs; validates target same deck and immutable source plus current head and logical undo pointer. Target complete manifest becomes expected+1, preserving current deck identity and createdAt with one new monotonic modifiedAt. Preserve every remaining field, including unknown/source-qualified identities, exact printing/finish, role evidence, category order, primer and complete package graph. No-op restore still creates revision/group/recovery. Recovery references exact pre-restore expected revision, has RECOVERY kind/selected target, and remains enumerable after undo. Append ordinary undo link(before=expected,result=expected+1,previous=current logical pointer); update head/undo state in same transaction. Insert revision before receipt, then recovery row referencing receipt and existing predecessor/target; no cyclic insert dependency. All writes rollback together.

CAPTURE/RESTORE join existing global operation-ID namespace using additive CLDR tags4/5; preserve tags0..3 byte-for-byte and fixed goldens. Fingerprint exact deck/expected/label or target+recoveryLabel. Replay validates matching request/kind/deck, receipt sequence and checkpoint association, CAPTURE result=expected, RESTORE result=checked expected+1, recovery source=expected and requested target. Return original IDs/historical result, with no clock/ID/new row; replay does not consult current head even after branching/corruption there. Shared receipt readers accept new kinds without treating them as APPLY/UNDO. Restore→undo exposes pre-restore content at another new revision and prior logical branch.

List newest creation sequence first. Cursor framed version/receipt epoch/last sequence/SHA256 of framed deck identity; verify scoped anchor. Any successful deck operation conservatively invalidates old epoch cursor. Retain PageRequest<=100, SqlRequest.MAX_ROWS101, bounded projections/codec limits and indexed queries; no limit bumps or truncation. Load/preview consistent transaction. Preview cancellation produces no writes.

## Package structural compatibility prerequisite

Current DeckSnapshotStore.payload validates a package-stripped copy, create/duplicate/undo validation uses package-rejecting DeckPatchReducer. Widening only the read guard would leave duplicate contributions pointing at old entry IDs. Ship coherent whole-manifest validation and duplicate/undo support before version restore.

One pure bounded structural validator reuses existing name, entry-count, entry/label/category/role-override and timestamp invariants; do not duplicate subtly different rules. It preserves immutable input. Validate unique instance IDs, bounded valid instance/package/version/contribution IDs, every contribution deckEntryId exists, positive contribution quantities, and unique (packageEntryId,deckEntryId) pairs within each instance. Sum quantities across ALL instances per deck entry using Long, rejecting sums beyond entry.quantity. Manual remainder can be zero or positive. One package entry may split over deck entries; several package entries may contribute to one entry. Multiple instances of same package/version valid. Preserve contribution ordering/policy/evidence/unknown metadata. No external package-version availability required; do not infer identity from names. The pure helper certifies graph structure only, not complete CLDK representability. Bound its visited entry/package/contribution/label/override collections using existing per-list ceilings and <=100,000 visited elements, with cancellation checks; it does not replace the complete codec budgets. Existing encode/decode remain mandatory at persistence boundaries and enforce all nested lists, strict UTF-8, exact encoded bytes and decimal limits. No second counting serializer or framework. Exact codec bounds:8,388,608bytes;10,000entries/ordinarylist;1,024categories;100,000aggregate list elements;1,024-byteIDs;1,048,576-byteordinarytext;4,096decimalprecision. Empty package instances remain valid. Existing codec non-cancellation limitation remains explicit; do not claim strict cancellation inside serialization.

Whole create/read/capture/restore/undo/duplicate use this validator, mapping caller-invalid vs stored-corrupt appropriately. Primitive APPLY retains explicit package-bearing mutation restriction until its own contribution-safe package capability is implemented. Package update/removal remains retained B09, not deferred by this slice. Undo's clock check must not route through a package-rejecting reducer; validate time directly with identical invariant.

Duplicate generates fresh deck/entry/package-instance IDs, remaps role overrides and EVERY contribution.deckEntryId, preserves package IDs/version IDs/policies/packageEntry IDs/quantities/order and all other fields. Reject collisions with source/new IDs within relevant identity domains; validate complete candidate before any write. Replay generates nothing. Whole restore/undo replace complete historical graph; never mix old contributions with current entries.
