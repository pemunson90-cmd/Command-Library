Preserve pure DeckPatchReducer semantics: every nonempty accepted patch increments revision once, even net-equal content; empty patch returns unchanged snapshot but inserts a reconciliable receipt. Empty patch does not consume or create an undo group, uses the current modifiedAt and does not call Clock. No redo promise. No-undo returns NOT_FOUND without receipt. Separate LocalDeckLibrary remains complete and compatible.

## Schema10→11 additive boundary

Keep all38 existing entities and data unchanged. Add two tables, no pruning or source/profile lifecycle FK:

- `deck_undo_link`: PK(provider,deck_id,link_revision), before_revision, nullable previous_link_revision. Both link_revision and before_revision FK same-deck deck_revision; previous pointer FK same-deck deck_undo_link; NO ACTION, matching indices. Insert-only. A normal nonempty patch at revisionR creates linkR whose before_revision is the actual prior head revision and previous pointer is the prior logical undo pointer.
- `deck_undo_state`: PK(provider,deck_id), head_revision, nullable undo_link_revision. Head FK same-deck deck_revision; undo pointer FK same-deck deck_undo_link; NO ACTION, matching indices. Stores the logical undo head independently of monotonic content revision. No state row is valid ONLY for an untouched revision0 library deck with no undo links; first nonempty apply initializes state. An empty patch leaves it absent/unchanged. Existing revision>0 with missing state or mismatch with current head is corruption, never silently repaired.

Normal apply: within one IMMEDIATE transaction replay lookup, epoch overflow check, current bounded validated snapshot, expected CAS, current undo-state validation, clock, reducer, encode candidate; insert immutable revision, conditionally update head projection WHERE revision=expected, insert undo link, insert/update state, insert receipt last. Undo: replay first, CAS/current and state/link validation, load the link's validated immutable before snapshot; append NEW revision current+1 with target content and current deck identity/createdAt, injected now modifiedAt, update head, advance state pointer to selected link.previous, receipt last. Undo creates no undo link, so undo does not toggle forever. Revision overflow fails before writes. Clock exception static INTERNAL, backwards time rejected consistently with reducer; no clamping/fabricated time. CreatedAt must agree across stored same-deck history. Every write affects exactly one expected row or entire transaction rolls back. No-undo and unsupported package targets consume no op ID.

Example A0→B1(link1 before0 previousnull)→C2(link2 before1 previous1); undo→B3(pointer1), undo→A4(null), editD5(link5 before4 previousnull), undo→A6(null). Branch example undo once→B3(pointer1), editD4(link4 before3 previous1), undo→B5(pointer1), undo→A6(null). Persist pointers across new adapter/connection/reopen; immutable old revisions/receipts untouched. selectedLink.link_revision > 0 and selectedLink.before_revision == selectedLink.link_revision - 1; selectedLink.link_revision <= currentHead; previousLink < selectedLink and previousLink <= beforeRevision. Define content equality as exact DeckSnapshot equality ignoring ONLY revision and modifiedAt: deck ID/createdAt and every other field remain equal. Current content must equal the immutable result at selectedLink.link_revision, or revision0 when the logical pointer is null. The selected link before snapshot must equal its predecessor link result content, or revision0 if previous is null. Load/validate those bounded reached snapshots and compare, so a wrong pointer to an existing same-deck older link cannot silently undo unrelated content. Validate selected and immediate predecessor identities/types/bounds/FKs each step; no unbounded full-chain scan per operation, no recursive walk. Each undo validates the newly exposed predecessor before publishing its pointer. Corruption anywhere reached fails closed. No retained-history completeness claim for unread future links.

Extract internal DeckSnapshotStore(Database, DeckPayloadCodecPort) for current/historical bounded reads, receipt replay, epoch, exact-row writes and transaction wrapper; keep DeckLibraryRows/Requests shared. Public SqlLocalDeckLibrary retains unchanged four methods and delegates helpers; separate public SqlLocalDeckEdits owns apply/undo through the same store. One centralized recognized receipt-kind set includes all four methods. Reuse metadata-before-blob guards, SHA256/projection/common graph validation and historical-vs-current separation. Never select potentially unbounded blobs before metadata checks; no second model/SQL framework. No deletion, storage compaction, migration rewrite or dependency pin changes.
