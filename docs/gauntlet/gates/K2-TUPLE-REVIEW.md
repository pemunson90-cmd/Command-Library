# K2 tuple review: compileSdk 36 to 37

Verdict: ACCEPT-WITH-CHANGES

Reviewer: Claude Code reviewer subagent (strongest model tier per D-10), separate context from the probe author, 2026-10-12 UTC. Evidence under review: [K2-TUPLE-PROBE.md](K2-TUPLE-PROBE.md). Binding under review: `android_sdk.compile` 36 to 37 (`platforms;android-37.0`); target 36, min 23, build-tools 36.0.0 and all library/plugin versions unchanged. The reviewer did not rerun Gradle. Checks are primary-source documents, freshly downloaded artifacts, AGP bytecode and the probe's retained outputs.

## Findings

1. BOM mapping confirmed. `curl https://dl.google.com/dl/android/maven2/androidx/compose/compose-bom/2026.09.00/compose-bom-2026.09.00.pom`: `androidx.compose.ui:ui` 1.12.1, `androidx.compose.material:material-ripple` 1.12.1, `material-ripple-android` 1.12.1, `material3` 1.4.0.
2. minCompileSdk 37 confirmed in the released AARs. Fresh Google Maven downloads into `scratchpad/review-aar/`: `material-ripple-android-1.12.1.aar` (SHA-256 `795d8742165875ee96383ca64ff4cd8bc12b83efb0918f68472e7c2f9d5826df`) and `ui-android-1.12.1.aar` (SHA-256 `3f1ae17e237d9dc0a2a0f42cb04b85b8de6e12f67adc5f5c12173fe31e501cb2`). `unzip -p <aar> META-INF/com/android/build/gradle/aar-metadata.properties` prints `minCompileSdk=37`, `minCompileMinorSdk=0`, `minAndroidGradlePluginVersion=9.1.0` for both. https://developer.android.com/jetpack/androidx/releases/compose-ui (1.12.0-alpha01): "Updated Compose compileSdk to API 37."
3. Only Compose drives the bump. Scanning `aar-metadata.properties` of every AAR in the probe's Gradle cache: the nine Compose 1.12.1 artifacts named in the diagnostic declare 37; activity 1.13.0 and core 1.18.0 declare 36; material3 1.4.0 declares 35; room3-runtime 3.0.3, sqlite-bundled 2.7.1 and datastore 1.2.1 declare 34.
4. AGP 9.4 supports compileSdk 37. https://developer.android.com/build/releases/agp-9-4-0-release-notes: "The maximum API level that Android Gradle plugin 9.4 supports is API level 37." `javap -c` on `ToolsRevisionUtils` in `builder-9.4.1.jar` (SHA-1 `af1135b3...e49ef`, equal to Google Maven `builder-9.4.1.jar.sha1`): `MAX_RECOMMENDED_COMPILE_SDK_VERSION = new AndroidVersion(37, 2)`. That is the source of the diagnostic's "for example 37.2"; 37.0 is inside the range.
5. build-tools 36.0.0 is acceptable. Same release notes table: SDK Build Tools minimum 36.0.0, default 36.0.0. Same bytecode: `MIN_BUILD_TOOLS_REV = "36.0.0"` and `DEFAULT_BUILD_TOOLS_REVISION = MIN_BUILD_TOOLS_REV`. AGP 9.4.1 does not require newer build-tools; `build-tools;37.0.0` exists but is not needed. The retained success log (`probe-run3.log`) has no build-tools warning.
6. No runtime behavior change from compileSdk. https://developer.android.com/build ("Configure your build", targetSdk section): "The value of targetSdk is not connected to the value of compileSdk" and "compileSdk gives you access to new APIs / targetSdk sets the runtime behavior of your app". The AGP diagnostic itself says compileSdk "can be done separately from updating targetSdk (which opts the app in to new runtime behavior)". Retained APK `aapt2 dump badging`: `compileSdkVersion='37'`, `targetSdkVersion:'36'`, `minSdkVersion:'23'`.
7. The alternative is not materially better. BOM 2026.08.00 maps ui/material-ripple to 1.12.0; both 1.12.0 AARs also declare `minCompileSdk=37`. BOM 2026.06.01 (next older; no 2026.07.x in `compose-bom/maven-metadata.xml`) maps them to 1.11.4; both 1.11.4 AARs declare `minCompileSdk=35`. So 2026.06.01 is the newest BOM whose ui and material-ripple accept 36 (its other artifacts not checked). It downgrades Compose a full minor, needs its own probe, and excludes BOM 2026.08.00 and every later release observed; Compose UI 1.13.0-alpha03 notes already say "compileSdk for Compose libraries updated to 37.1". The compileSdk bump has no runtime cost. Keep BOM 2026.09.00 with compileSdk 37.
8. The package is pinnable. https://dl.google.com/android/repository/repository2-3.xml: `platforms;android-37.0`, api-level 37.0, revision 2, `platform-37.0_r02.zip`, SHA-1 `ed8ebf7f8822a4de5686d427f237d2fa30ff7410`. 37.1 and 37.2 are also published; 37.1 will be needed for Compose 1.13 and is within AGP 9.4.1's 37.2 ceiling.
9. Probe claims re-observed from retained outputs (not rerun): APK SHA-256 `d6a605b4...e94a` and 17,619,112 bytes match; merged manifest min 23 / target 36; `zipalign -c -P 16 -v 4` gives 12 `.so (OK)` and "Verification successful"; `readelf -lW` on the 12 extracted `.so` gives 44 LOAD segments, all `0x4000`; exported Room3 schema `1.json` has the FTS5 virtual table with `unicode61`; `TEST-BundledFts5JvmTest.xml` tests=1 failures=0 with `sqlite_version=3.50.1`; build-classpath dump shows KGP and Compose plugin 2.2.10 and KSP `2.2.10-2.0.2 -> 2.3.12 (c)`; runtime dump shows kotlin-stdlib 2.2.10 and coroutines-core 1.9.0; cache holds only `kotlin-compiler-embeddable` 2.2.10; command-line tools SHA-1 `e025545c...5f60` is present in repository2-3.xml; repo wrapper pins the K1 Gradle SHA-256.

## Inaccuracies in K2-TUPLE-PROBE.md (non-blocking)

13. The run logs exist only in the session scratchpad and are not committed. The reviewer read them, so nothing is fabricated, but the evidence is not durable.
