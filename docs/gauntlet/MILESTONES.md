Each component delivers non-UI contracts before consumer implementation. M2 profile/game transfer and M3 general transfer share the accepted transfer interface; implement minimal profile schema earlier, don't fake a missing dependency. All UI accessibility/task checks run with feature delivery; M8 is comprehensive verification, not first accessible build.

Gate reports record actual build SHA/test commands/results/run URLs/screenshots/coverage delta and exact remaining issues. Unrun physical tests cannot be passed by model review. Public release/sync/multi-device state stay POST_RELEASE. Do not force all milestones into one session: follow bounded task queue and publish early after every substep.
