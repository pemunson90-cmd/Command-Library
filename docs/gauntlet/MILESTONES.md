# MILESTONES: resumable delivery sequence

D17 authorizes reviewed routine technical-stage progress and bounded model succession. Technical gates still require artifacts/checks/independent review; budget/scope relaxation and true product/manual/tool-permission barriers remain recorded decisions. No stage becomes complete because planned.

D-19 (Pat, 2026-10-11): version 1 is the complete Android app (phones, foldables, tablets). Windows is version 2 and starts only after M9. No Windows code, packaging, CI job or Windows-only adapter is built in version 1. Keyboard, mouse, hover, right-click, drag/drop, resizable windows and large-screen layouts stay version 1 on Android.

Each component delivers non-UI contracts before consumer implementation. M2 profile/game transfer and M3 general transfer share the accepted transfer interface; implement minimal profile schema earlier, don't fake a missing dependency. Gate reports record actual build SHA/test commands/results/run URLs/screenshots/coverage delta and exact remaining issues. Unrun physical tests cannot be passed by model review. Public release/sync/multi-device state stay POST_RELEASE. Do not force all milestones into one session: follow bounded task queue and publish early after every substep.
