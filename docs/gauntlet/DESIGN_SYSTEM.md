# DESIGN SYSTEM

Status: not started. Written at Gate 2, before any UI code. The ui-auditor checks every screen against this file.

## Sections (filled at Gate 2)

1. Principles
2. Tokens: color, typography, spacing, shape, elevation, motion
3. Themes: light, dark
4. Color-identity accents (W, U, B, R, G, colorless, multicolor)
5. Components and their states (default, hover, focus, pressed, disabled, error)
6. Card rendering rules (list row, grid tile, detail, multi-face, (n) display)
7. Iconography and mana symbols
8. Layout by window size class and posture, hinge rules
9. Desktop affordances: hover, focus rings, context menus, keyboard shortcuts, drag-and-drop
10. Accessibility: text scaling, contrast targets, touch target sizes, screen reader labels
