# ENGLISH_SEARCH_v1 trusted profile (design input)

Scope: explicit user-triggered personal English-card acquisition through Scryfall's English search traversal. It covers only cards returned by the fixed search scope; rules, rulings and bulk files need separate reviewed profiles and consumers. It does not make refresh automatic or admit any mixed/default bulk feed.

| Field | Proposed trusted value |
|---|---|
| Intent/source identity | `DownloadKind.CATALOG`; provider/source `scryfall`; language `LanguageTag.ENGLISH`; stable intent/profile ID `scryfall-english-search-v1`; intent `version = "ENGLISH_SEARCH_v1"`. The version identifies this local policy, not an upstream release. `sourceVersion = Knowledge.Unknown`, `sourceDate = Knowledge.Unknown`, expected checksum = unknown/null; do not derive any of these from fetch time, ETag or Last-Modified. |
| Query policy | `AcquisitionSource.EnglishSearch(firstPage = EnglishSearchPageCodec.INITIAL_URI, queryPolicyVersion = "english-search-query-v1")`; `profileVersion = "english-search-v1"`. Initial URI is the codec's exact constant. Require `lang:en`, `unique=prints`, extras and variations included, multilingual excluded, set ascending, page 1; each returned card must say `lang=en`. Follow only codec-validated same-origin `next_page` values, exact query scope, sequential page numbers, no warnings, 1–175 rows/page, unique printing IDs within each page, stable `total_cards`, and terminal coverage exactly equal to that total. Traversal is non-atomic; expose it as retrieved over an interval, never as an immutable snapshot. |
| Numeric bounds | Transfer response bytes across the traversal: 2 GiB maximum; normalized JSONL artifact bytes: 2 GiB; decoded bytes: 2 GiB; records: 500,000; pages: 2,858 (ceil(500,000/175)); page response: 16 MiB; serialized record: 8 MiB; stream chunk: 64 KiB; JSON nesting: 32. The 2 GiB/500k/8 MiB/64 KiB/32 ceilings reuse `CatalogBulkImportLimits`/full-feed framing bounds; 2 MiB batching is importer batching, not a disk-space or whole-artifact bound. The 16 MiB page ceiling is an explicit memory bound that permits an 8 MiB singleton plus envelope. Genuine probes on 2026-10-12 measured 860,496 bytes for page 1 and 866,303 bytes for page 663 (175 and 159 records); 116,009 was the observed total. Those two pages support the page cap choice, but do not measure full traversal bytes, normalized artifact size, decoded/import expansion, staging space or WAL. The 2 GiB values are ceilings, not estimates of expected use. |
| Endpoint and request | Endpoint ID `scryfall-search-v1`; origin `https://api.scryfall.com:443`; no redirect origins. `validateWireTarget` for English search already requires `actual == requested` plus valid codec page URI; retain this no-redirect rule. GET, no secret/authentication, `Accept: application/json`, and a build-supplied truthful `User-Agent: CommandLibrary/<actual app version>` (never a fabricated version). Timeout: the existing engine RequestSpec fixes120 seconds per request (LocalAcquisition guardedStream); do not claim an endpoint-level60-second knob. Start no request until at least 600 ms after the prior request start. Use endpoint `requestsPerSecond=2` for the documented500ms ceiling; LocalAcquisition.authorizeWireDispatch independently waits outside the consent gate until600ms and revalidates before enqueue. Avoid an unnecessary one-second throttle. |
| Retry and admission | `RetryPolicy(maxAttempts=1, initialDelay=30s, maximumDelay=24h, honorRetryAfter=true)` with `RetryClassification.NEVER_AUTOMATIC`; a 429 pauses at least 30 seconds or the longer supplied interval and requires explicit user resume. No automatic retry, refresh, parallel traversal or per-launch check. Existing local cache is reused; any refresh is an explicit Download action. Require current durable network consent and English-language consent before queue/dispatch as existing acquisition flow requires. |
| Disk policy | Reserve up to the configured 2 GiB transfer/artifact ceiling before acquisition (free-space preflight; fail without deleting the active generation if unavailable). This is a transfer reserve only. The source/code evidence does not establish temporary staging, database, index or WAL peak cost; record and measure those on device separately before claiming a supported end-to-end disk budget. Do not silently count the transfer reserve as staging/WAL headroom. |

The fixed URI and parser bounds are pinned in `EnglishSearchPageCodec`; request equality, English scope, no checksum and `maxNesting >= 32` are enforced in `LocalAcquisition.validate`. The same-origin wire-target check is in `validateWireTarget`, followed by `endpointFor` for the actual URI. `DownloadIntent`, `EndpointProfile`, `RetryPolicy`, `RequestSpec` and `AcquisitionLimits` supply the required contract fields. Existing bulk caps are in `FullCatalogContracts.CatalogBulkImportLimits` and `JsonArrayFramer`.

Upstream check: Scryfall's search documentation says 175 results/page; its rate page states `/cards/search` is 2/second (500 ms), 429 limits access for 30 seconds, and clients must reduce overages. Fetched successfully 2026-10-13 from https://scryfall.com/docs/api/cards/search and https://scryfall.com/docs/api/rate-limits. The profile's 600 ms remains the repository's stricter established pacing policy, not an upstream requirement. Existing source review: `docs/verification/k3-downloads/PERSONAL-SOURCE-REVIEW.md`, reviewed 2026-10-12, documents the exact URI, 116,009 count, first/last-page probe sizes, 663-page observation and personal-cache scope.

Validation cases for the eventual trusted factory/profile:

1. Accept only the exact initial URI and valid same-origin next pages preserving `lang:en`/prints flags; reject another query, host, port, redirect, skipped/repeated page, warning, non-English card, duplicate ID, changed total or terminal coverage drift.
2. Reject before dispatch if any byte/page/record/count/nesting limit is exceeded; enforce 600 ms start spacing, one automatic attempt, no credentials, and the actual application User-Agent. A 429 must stop dispatch for at least 30 seconds and wait for explicit resume.
3. Reject plans whose intent language/kind, source, URI, policy version or consent differs from this profile. Keep `sourceVersion`/`sourceDate` unknown and consistency `NON_ATOMIC_TRAVERSAL`.
4. Refuse acquisition if the transfer reserve is unavailable; activation must also pass a separately measured staging/WAL free-space check. On any failure, preserve the previously active catalog.
