Both membership foreign keys exactly match existing parent primary keys: printing (generation_id,provider,printing_id), Oracle (generation_id,provider,oracle_id,language). Its printing-prefix primary key and Oracle-prefix lookup index cover the respective child lookups.
Slot -1/WHOLE versus nonnegative/FACE preserves original printing-face ordinal and repeated same-Oracle faces without inventing canonical face indices; enforce kind/slot consistency at the write/decode boundary and de-duplicate printing identities in lookup.
Add exactly five provenance columns: catalog gets input_kind/artifact_job_id/source_payload; rules gets input_kind/artifact_job_id. Apply NOT NULL DEFAULT 'USER_CONTENT_URI' to input_kind on both tables, with matching Room ColumnInfo defaults; preserve existing non-null content_uri and every original payload byte.
Backfill only complete non-null Oracle triples as WHOLE/-1; all-null triples yield no membership, partial-null triples must explicitly abort migration (SQLite composite FKs alone permit them). Use plain insertion and do not silently ignore invalid or dangling legacy relations.
Printing deletion cascades its memberships; Oracle deletion remains blocked while referenced. Cleanup must delete child printings/memberships before individual Oracles, or use the generation cascade after removing/replacing its active pointer; delete FTS rows explicitly. No acquisition-job FK means job/artifact deletion cannot remove installed catalog/rules data.
After-EOF bounded membership resolution handles later canonical targets; per-batch deferred FKs do not. Persist pending evidence in retained printing payloads, resolve against same-generation canonical identities, and reject unresolved targets before activation. Ordinary printing Oracle FKs still require their canonical row before printing insertion.
Preserve all 16 existing schema3 entities except the stated additive columns, including acquisition rows, rules audit rows and active pointers; source codecs must validate new origin/job fields against versioned payloads without rewriting legacy payload versions.
