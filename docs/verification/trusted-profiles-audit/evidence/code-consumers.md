CARDS: CatalogBulkImportSource fully specifies a VERIFIED_ARTIFACT input. Every field must equal the artifact: provider, ENGLISH_CARDS scope, framing, compression, bytes, sha256, sourceDate, requestedUri and notice. LocalBulkCatalog also requires that the consentId supplied by the binding is present exactly when the input kind is VERIFIED_ARTIFACT, and that recordCount equals the printings staged. Nothing implements the binding (CatalogVerifiedInputBinding), and neither LocalBulkCatalog nor LocalAcquisition is constructed in AppGraph. No AcquisitionLimits instance exists for the search profile. Compatible values can be derived: maxRecords<=500,000; maxRecordBytes<=8 MiB; min(maxArtifactBytes,maxDecodedBytes)<=2 GiB; 64 KiB chunks; maxNesting=32.

RULES: The import accepts only a user content:// URI, plus caller-supplied Knowledge metadata. There is no VerifiedArtifact/ENGLISH_RULES binding. The rules_corpus input_kind/artifact_job_id columns exist but are never written. The parser never infers the effective date or version; the shell passes Unknown. Defaults: 8 MiB input, 16 KiB line, 20,000 entries, 64 KiB entry, 512 continuation lines, 256 refs/entry, range expansion 26. Encoding is strict UTF-8; a leading BOM is stripped; CRLF, LF and lone CR all end lines; NUL and control characters are not rejected. The only hard structural requirement is at least one numbered rule, plus Contents and body consistency. There is no production path from a downloaded TXT to a rules install.

RULINGS: Only a model type (Ruling), the CatalogCounts.rulings field (always 0), the acquisition scope enum RULINGS_LANGUAGE_NOT_ASSERTED and the CachePolicy.retainRulings flag (persisted, never read) exist. There is no import contract, mapper, storage table or UI. The gzip, JSON-array/JSONL and strict-JSON components in :feature:catalog could be reused, but they are internal to that module and typed to the card limits.

NOTICE: Nothing in production creates a SourceNotice with real text, and no Scryfall or Wizards attribution text exists anywhere. For VERIFIED_ARTIFACT, the notice must equal the artifact provenance notice, which equals the plan request notice.

DISK: There is no free-space preflight, no WAL/journal configuration and no measured staging numbers. Raw JSON is stored several times per generation, and retired generations are never reclaimed.

## Discrepancies
- catalog/LocalBulkCatalog.kt:50 persists format=ScryfallCodec.FORMAT='scryfall-json-array' even for JSONL search artifacts; catalog/LocalCatalogIdentities.kt:99 requires that label on read.
- catalog/LocalCatalog.kt:259 always reports Provenance.version Unknown, even though catalog/LocalBulkCatalog.kt:52 stores source_version.
- storage/Migration3To4.kt:34-35 added rules_corpus.input_kind and artifact_job_id, but model/LocalRulesContracts.kt has no input-kind field and rules/LocalRules.kt:40 never writes them.
- AcquisitionLimits allows maxNesting up to 128 and EnglishSearch requires >=32 (model/AcquisitionContracts.kt:35; catalog/LocalAcquisition.kt:754), while CatalogBulkImportLimits caps nesting at 32 (model/FullCatalogContracts.kt:26) and page parsing is fixed at 32 (catalog/EnglishSearchPageCodec.kt:48).
- JsonLinesLimits caps records at 128 KiB (catalog/JsonLinesFramer.kt:21), but the FullFeedFramingLimits constructor (:42-43) allows 8 MiB. This is intentional, but there are two ceilings.
- BoundedRecordBatches (catalog/BoundedRecordBatches.kt) duplicates the CatalogBulkImportLimits batch constants and is not instantiated; LocalBulkCatalog.kt:89-98 reimplements the batching inline.
- settings/SettingsStoreFormat.kt:80 defaults retainRulings=false, while its own comment (:69-72) says the spec requires retained rulings.
- model/CatalogContracts.kt:188-194 Ruling has no field for the ruling source (wotc/scryfall) and needs a non-blank ProviderIdentity id that the task-listed Scryfall ruling fields do not provide.
- Bulk records are mapped with hash=null (catalog/LocalBulkCatalog.kt:69), but the result provenance uses proof.rawHash (:118). Per-record provenance therefore differs from generation provenance until read back.
- The VERIFIED_ARTIFACT contentUri must exist before the locator lease that creates the content URI (catalog/AndroidVerifiedArtifactLocator.kt:37-40; catalog/AcquisitionArtifactProvider.kt:135); no code checks that they are equal.
- model/LocalRulesContracts.kt:28 allows expectedBytes==0 for rules, while catalog requires >0 (model/FullCatalogContracts.kt:54).
