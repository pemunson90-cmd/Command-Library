## Prioritized gaps and next implementation step

1. **Preserve failure status and agree on durable 429 behavior before guarded factory integration. VERIFIED_CODE:** [OkHttpNetworkClient.kt](../../../android-app/data/network/src/main/kotlin/com/architectpsg/commandlibrary/data/network/OkHttpNetworkClient.kt) lines 185–239 converts non-2xx to transport failure; no `HttpMetadata` reaches acquisition for 429. [LocalAcquisition.kt](../../../android-app/feature/catalog/src/main/kotlin/com/architectpsg/commandlibrary/feature/catalog/LocalAcquisition.kt) lines 273/396/787 has a metadata-based rate-limit path, therefore that path is unreachable with this adapter. Adapter still records an origin cooldown; it does not ignore 429 entirely. Failed-job explicit resume restarts (at most three attempts), retaining charged reservations and cumulative transfer bytes (F42/43/50–56). **INFERRED_POLICY:** earliest bounded next step is a reviewed transport/engine contract correction and focused 429 tests; choose truthful waiting/resume semantics without automatic retries or silent consent/budget relaxation. Do not claim the draft's pause/resume behavior already exists.

2. **Bind every physical request, including discovery, to authority. VERIFIED_CODE:** exact-spec identity registration and dispatch-time consent/Wi-Fi recheck exist in `LocalAcquisition.authorizeWireDispatch` lines 418–477; the client's default guard still enqueues directly. AppGraph does not construct acquisition/network services. `TrustedEnglishSearchProfile` now supplies canonical validation/endpoint policy, so Claude X02's blanket “no production validator exists” is stale. It does not provide the guarded composition, connectivity adapter, permissions or UI. An arbitrary English-labelled RemoteFile passes generic engine checks (F71), but fails the new canonical English helper if that helper is wired. **UNRESOLVED:** no discovery source variant/registered request authority exists (F90/91). Fetching metadata/HTML through a second ungated client is not an acceptable workaround. Discovery locators, redirects and finite caps are reviewed application policy, not guaranteed upstream grammars.

3. **Make request identity and representation checks real. VERIFIED_CODE:** engine constructs fixed 120 s overall RequestSpecs, `NEVER_AUTOMATIC`; there is no EndpointProfile timeout field. Request headers can override Accept; engine currently supplies Range/validator headers, not profile-specific Accept (X04/F37/F57/F92). **INFERRED_POLICY:** composition must supply actual app-version User-Agent and suitable JSON/HTML/TXT Accept. HTTP content encoding and `.gz` file compression are distinct: identity preserves compressed file bytes for one bounded consumer gzip decode.
